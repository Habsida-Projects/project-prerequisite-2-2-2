# Spring MVC: стартовый шаблон

Учебное WAR-приложение с Java-конфигурацией Spring MVC и Thymeleaf для внешнего Tomcat. После запуска открывается приветственная страница. Модель Car, сервис, контроллер `/cars` и страницу cars.html нужно реализовать самостоятельно по заданию.

## Требования

| Инструмент | Версия |
| --- | --- |
| JDK для сборки и запуска | **21** |
| Maven | **3.9.16**, устанавливается Maven Wrapper |
| Apache Tomcat | **11.0.27**, проверенная версия |
| Spring Framework | **7.0.10** |
| Jakarta Servlet API | **6.1.0**, предоставляет Tomcat |
| Thymeleaf | **3.1.6.RELEASE**, модуль thymeleaf-spring6 |

Скачайте JDK 21 и [Tomcat 11, Core ZIP](https://tomcat.apache.org/download-11.cgi). Закреплённая проверенная версия доступна также в [архиве Apache](https://archive.apache.org/dist/tomcat/tomcat-11/v11.0.27/bin/). Для первого запуска Wrapper и загрузки зависимостей нужен интернет. Устанавливать Maven отдельно не требуется.

Этот шаблон предназначен для Tomcat 11 и пакетов `jakarta.servlet`. Tomcat 9 и старые `javax.servlet` с ним несовместимы. В pom.xml проверяется JDK 21; выбирайте её и для Maven, и для Tomcat. Провайдер slf4j-jdk14 направляет сообщения библиотек в Java Util Logging, используемый Tomcat, чтобы ошибки приложения были видны в журналах.

## Запуск в IntelliJ IDEA Ultimate

1. Откройте pom.xml как Maven-проект и дождитесь загрузки зависимостей.
2. В Project Structure выберите Project SDK **21**. В настройках Maven Runner выберите JRE **21**; для Maven используйте Wrapper.
3. Создайте Run Configuration: **Tomcat Server → Local**. Укажите распакованный Tomcat **11**, JRE **21** и свободный HTTP-порт, например **8080**.
4. На вкладке Deployment добавьте **Artifact → spring-mvc:war exploded**. Если IDE предлагает Fix, выберите тот же артефакт. Название может отличаться в зависимости от имени импортированного модуля.
5. Задайте **Application context: /spring-mvc** и URL запуска `http://localhost:8080/spring-mvc/`.
6. Запустите конфигурацию. На странице должны появиться два английских сообщения и строка «Приложение Spring MVC запущено!».

## Если приложение не запускается

- **JDK:** сравните JAVA_HOME, вывод Wrapper, Project SDK, Maven Runner JRE и Tomcat JRE — везде нужна версия 21.
- **404:** проверьте Application context, HTTP-порт и журнал развёртывания. Сначала откройте приветствие `/spring-mvc/`. `/cars` появится после выполнения задания.
- **Порт занят:** остановите другую свою конфигурацию или задайте свободные HTTP/JMX-порты в IDE.
- **javax/jakarta или ошибки классов:** проверьте, что запускается Tomcat 11 и выполнена чистая сборка нового шаблона.
- **Изменение HTML не видно:** обновите ресурсы exploded-артефакта. При запуске готового WAR сначала пересоберите и заново разверните приложение.
